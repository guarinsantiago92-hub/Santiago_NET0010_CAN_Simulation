# Santiago Guarin - NET0010 CAN Simulation

This project will simulate CAN communication between the controllers of an industrial conveyor system.

I will use Python to generate CAN messages from at least three simulated controllers. The message identifiers, signal definitions and transmission intervals will be selected during Sprint 2, following the project requirements.

I will use Wireshark on Windows 11 to examine the generated CAN traffic and investigate communication faults without physical CAN hardware.
